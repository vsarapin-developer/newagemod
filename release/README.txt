New Age QoL — плагин для «Новой Эры» (nura.biz)
================================================

УСТАНОВКА

1. Скачать BepInEx 5.4.23.5 x64:
   https://github.com/BepInEx/BepInEx/releases
   Распаковать в папку игры — туда, где лежит NewAgeClient.exe.

2. Положить NewAgeQoL.dll в папку New Age\BepInEx\plugins\
   Если папки plugins нет — создать её.

3. Запустить игру.

Обновление: просто заменить NewAgeQoL.dll новым. Настройки не сбросятся.
Удаление: удалить NewAgeQoL.dll. Настройки останутся в
BepInEx\config\newage.qol.cfg, при возврате плагина всё будет как было.


НАСТРОЙКИ

В настройках игры, под кнопкой «Сбросить положение чата», появится
кнопка настроек мода. Каждую возможность можно выключить отдельно.
Зелёная галочка — включено, красная — выключено.


ЧТО УМЕЕТ

Кнопка возврата в Иллениум — слева внизу, над кнопкой сумки.
В бою скрыта.

Кнопка артефактов — над кнопкой города. Сдаёт все вещи артефактной
редкости в хранилище: сама доходит до банка и хранилища, снимает
надетое вместе с запасными слотами и складывает. Пройденные шаги
пропускает. После сдачи меняет картинку и той же кнопкой возвращает
всё обратно, надевая вещи на прежние места. Пока идёт работа, из
хранилища не выйти, чтобы операция не оборвалась.

Кнопки банок — справа от кнопок города и артефактов: жизнь, мана,
энергия, грибы. На иконке остаток в сумке, нажатие пьёт до полного
и останавливается, как только полоса заполнилась. Предмет задаётся
в настройках по id или по названию. В бою кнопки скрыты.

id предмета в названии — у вещей, используемых вне боя, к названию
в описании дописывается id в скобках. Его и вписывают в настройки
кнопок банок. На рынке id не показывается.

Пополнение в бою без ожидания анимации — выпил банку и сразу можно
жать умение, приём или каст, не дожидаясь, пока доиграет анимация
прибавки. Значение берётся то, что прислал сервер.

Поиск по сумке — строка под сеткой предметов, ищет по названию.

Вкладка «Контракты» — отдельная вкладка со своей иконкой; из прочих
вкладок контракты убираются, кроме вкладки «Все».

Иконки рецептов — у рецепта видно, какую вещь он создаёт, вместо
одинакового свитка. Маленький значок рецепта остаётся в углу клетки.

Подсветка своих строк — в системном логе строки с твоим ником
целиком зелёные.


ПРОВЕРКА

Мод — один файл без зависимостей, исходники открыты. Его можно собрать
самому одной командой (см. README на GitHub) или открыть декомпилятором
вроде ILSpy: обфускации нет, виден весь код.

Своей сети у мода нет: всё уходит через сетевой слой самой игры и теми
же запросами, что клиент шлёт, когда ты жмёшь то же самое руками. На
диск пишется только BepInEx\config\newage.qol.cfg. Логин и пароль мод
не видит, клавиатуру читает лишь в окне своих настроек при назначении
клавиши.

По умолчанию в лог идут только загрузка и ошибки. Подробности включает
[Log] Verbose = true в newage.qol.cfg.

BepInEx в архиве — официальная сборка 5.4.23.5 x64 с
https://github.com/BepInEx/BepInEx/releases


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

Лог игры: New Age\BepInEx\LogOutput.log
Строки плагина начинаются с «New Age QoL».
